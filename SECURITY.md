# Security Policy

## Supported versions

Security fixes are applied to the **latest released semver** published on GitHub Releases and
GHCR (`ghcr.io/campasachamp/plextraktbox:vX.Y.Z`). Older tags are not patched; upgrade to the
latest release.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use [GitHub Security Advisories](https://github.com/CampAsAChamp/plextraktbox/security/advisories/new)
to report privately. Include steps to reproduce, impact, and (if available) a suggested fix.

You should receive an initial response within **7 days**. After a fix is available, we will
coordinate disclosure through the advisory.
